## Описание проекта
Habit Tracker — веб‑сервис для отслеживания привычек. Пользователь создаёт привычки с указанием 
действия, места, времени, периодичности и длительности. Для приятных привычек можно задать 
вознаграждение или связать с другой приятной привычкой. Система отправляет напоминания в Telegram по 
расписанию.

В проекте реализованы:
- регистрация и авторизация через JWT;
- CRUD привычек с валидациями;
- фоновые задачи (Celery) для отправки напоминаний;
- планировщик (celery-beat) для проверки привычек по расписанию;
- Telegram‑бот для привязки chat_id и получения уведомлений.


## Установка:
1. Клонируйте репозиторий:
    ```bash
    git clone https://github.com/zelenyzar/habit_project/
    ```
2. Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```
3. Создайте файл `.env` рядом с `manage.py` и заполните переменные окружения: 
`SECRET_KEY`, `DEBUG`, данные подключения к PostgreSQL (`NAME`, `USER`, `PASSWORD`, `HOST`, `PORT`), 
`TG_TOKEN`, `ALLOWED_HOSTS`.
4. Примените миграции:
    ```bash
    python manage.py migrate
    ```
5. Создайте суперпользователя:
    ```bash
    python manage.py createsuperuser
    ```

## Использование проекта:
1. Запустите Redis (брокер сообщений для Celery):
    ```bash
    redis-server
    ```
2. Запустите сервер разработки:
    ```bash
    python manage.py runserver
    ```
3. В отдельном терминале запустите Celery worker и планировщик:
    ```bash
    celery -A config worker -l info -P solo
    celery -A config beat -l info
    ```
4. Для напоминаний в Telegram запустите бота:
    ```bash
    python manage.py runbot
    ```
5. Откройте в браузере:
    - сайт: http://127.0.0.1:8000/
    - документация API: http://127.0.0.1:8000/swagger/ или http://127.0.0.1:8000/redoc/
6. Зарегистрируйтесь через `/api/users/register/`, получите токены на `/api/token/obtain/` 
и передавайте access-токен в заголовке `Authorization: Bearer <token>`.

## Модели:

### User (пользователь)
Стандартная модель Django с кастомным профилем. Используется как основа для всех привычек и напоминаний.

### UserProfile (профиль пользователя)
Связана с `User` по OneToOne. Содержит:
- `tg_chat_id` — ID чата Telegram для отправки напоминаний;
- дополнительные поля для интеграции с внешними сервисами.

### Habit (привычка)
Основная модель проекта. Ключевые поля:
- `user` — владелец привычки (ForeignKey);
- `action` — описание действия;
- `place`, `time` — место и время выполнения;
- `is_pleasant` — флаг «приятная привычка»;
- `periodicity` — периодичность (в днях, 1–7);
- `duration_minutes` — длительность (в минутах, 1–2);
- `reward` — вознаграждение;
- `related_habit` — связанная привычка (только для приятных);
- `is_public` — флаг публичности;
- валидации: запрет одновременного указания `reward` и `related_habit`, требование, чтобы связанная привычка была приятной.
